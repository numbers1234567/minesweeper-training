# Minesweeper Training Utility

Just a little side project.
I aim to build some of my C++ skills while brushing up on algorithms and operating systems.

I aim to develop a utility which will focus on specific Minesweeper skills in real-time during play sessions.
(we all know we won't be reviewing historic plays).

Made with love, programmed by hand.

## Planned Features

1. Sound effect whenever efficiency drops
2. Sound effect whenever player is slower than a preset speed
3. Partial board hiding to drill jumps and short-term memory
